# Music Hub

一个仅供本人访问的 `Yorushika` 主题音乐站点，提供作品索引、Song Stories、
搜索筛选、本地收藏和登录保护的 Radio。

**无公开在线演示。** 旧 `music.yoruming.cn` 已停用；私人站点和 HLS 均需登录，
不能作为陌生访客的公开体验入口。阅读源码可从下方快速开始进入。

## 项目定位
- `Web App`：面向个人展示与轻量互动的 Flask 网站。
  - 中文解释：`Web App` 指通过浏览器访问并完成主要交互的应用。
- `MVP`：当前为可运行的最小可交付版本。
  - 中文解释：`MVP` 指保留核心能力、可被真实使用的最小版本。

## 当前状态（2026-10-02）
- 目录：以 Yorushika 官方艺人目录中的音乐发行为范围，整理 22 部作品、111 首独立曲目与 124 个曲序位置，保留发行日期、类型、封面、官方来源和复核日期。
- 页面：首页、作品集、单曲详情、搜索、Song Stories、Radio、策展说明与浏览器本地收藏。
- 作品页：22 部作品均使用完整策展档案；官方公开信息、本站聆听笔记、个人聆听路径、完整曲序与资料来源分区展示。
- 影像：沿用已有 Bilibili 入口。历史文档记录人工核验 24 条，当前线上页面显示 111；此轮未逐条复核，链接数量不能单独证明人工核验，统计文案与核验记录待专项对齐。
- Radio：57 个 Live 分曲文件，覆盖 2021《前世》、2022《月光》、2024《前世》和 2024《月与猫的舞蹈》，按演出与曲序播放，并显示“Live 标识 + 歌名”、当前曲目、近似进度、下一首和 25% 初始音量。
- 私密边界：正式入口为 `https://radio.yoruming.cn/`，全站与 HLS 均受 HTTP Basic Auth 保护并禁止搜索引擎收录；旧 IP 白名单入口仅作为回退。
- 工程：图片和字体已减重；数据库使用可回滚迁移；依赖带哈希锁定；具备集成测试。
- 数据：曲目与发行作品已拆分，多作品收录的同一首歌只保留一份曲目资料，并按作品分别保存曲序。
- 运维：Web 与 Radio 使用独立非 root 用户，Unix socket 放在 `/run`。
- 可靠性：5 分钟健康检查、每日 MySQL 备份、失败记录、完整发布快照和显式回滚已上线。
- 视觉：采用“夜鹿集 / YORUSHIKA ARCHIVE”内容型设计，中文说明为主、日文标题为作品标识。
- 版本库：`main` 是公开、可复现的唯一长期分支；Git 收口不等于服务器部署，线上版本仍以 `deployed-version.json` 为准。

### 本轮维护已上线

- 电台改为循环读取无损封装的播放缓存，不再每 4.713 小时靠正常退出和重启继续；原始 57 首 MP3 未修改。短音频多轮循环已在服务器验证，完整 57 首长轮次尚未人工验收。
- 播放失败有上限重连、时间表每分钟更新；主题、音量和收藏遇到浏览器存储异常可降级或明确报错。前端脚本按内容指纹更新地址，避免继续使用旧缓存。
- 部署临时目录不再删除用户指定目录；健康检查核对分片新鲜度、可获取性与 TS 结构，并兼容服务器 Python 3.10 的 FFmpeg 时间戳。
- 更新哈希锁定依赖并使用干净运行环境。114 项 Python 测试、12 项前端回归通过；Chrome 实际播放、跨页不断播、错误后自动恢复、收藏增删和 390 px 布局已验收。
- 最新 MySQL 备份已复制到 Mac 现有目录，SHA-256 一致且隔离恢复检查通过；自动异机备份和故障通知按用户决定另定。
- 本次线上来源为已核验的工作区内容发布，维护实现纳入本次 main 的 Git 交付；线上版本仍以内容指纹为准，本次不重复部署。完整发布指纹、回滚点和未验证边界见 [运维记录](./docs/operations.md#2026-10-02-可靠性维护发布)。
