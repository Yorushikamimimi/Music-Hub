# 项目总览（Overview）

## 1. 目标
本项目用于集中展示 Yorushika 相关歌曲内容，提供可视化浏览与筛选能力，并支持本地收藏。

## 2. 当前功能边界
- 包含：
  - 首页歌曲列表（分栏展示）。
  - 每日推荐（按日期种子随机）。
  - 搜索筛选（关键词、年份、热度/年份排序）。
  - 关于页展示（个人信息、技能、心愿单）。
  - 收藏系统（浏览器本地存储）。
- 不包含：
  - 评论/留言能力（已移除）。
  - 音频播放彩蛋（已移除）。
  - 头像上传能力（已关闭）。

## 3. 页面与路由
- `/`：首页（歌曲列表 + 每日推荐）。
- `/search`：搜索与筛选页。
- `/about`：关于页与心愿单展示。

## 4. 代码结构
- `app.py`：应用入口、配置注入、蓝图注册、413错误处理。
- `routes/main.py`：业务路由（index/search/about）。
- `models.py`：数据模型（当前仅 `MusicYorushika`）。
- `config.py`：环境变量读取、数据库连接与安全校验。
- `utils.py`：头像读取等工具函数。
- `templates/`：Jinja2 模板。
- `static/`：样式、图片、前端脚本。
- `netease_spider.py`：数据初始化/抓取脚本（带建表与写入逻辑）。

## 5. 关键技术说明
- `Blueprint`：Flask 的路由模块化机制。
  - 中文解释：把路由按业务拆分，便于维护。
- `ORM`：对象关系映射。
  - 中文解释：用 Python 类操作数据库，减少手写 SQL。
- `localStorage`：浏览器本地存储。
  - 中文解释：收藏数据保存在用户浏览器，不走服务端。
