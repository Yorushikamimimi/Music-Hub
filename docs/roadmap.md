# 迭代路线图（Roadmap）

## 已上线基线
1. 静态资源减重与缓存。
2. 真实作品目录、Song Stories 和官方来源。
3. Radio 私密边界、24 首白名单与非自动播放。
4. 移动导航和基础无障碍，不改整体视觉语言。
5. 可回滚数据库迁移与确定性目录同步。
6. 移除伪 HOT / 评分。
7. Web / Radio 非 root 目标配置。
8. 哈希依赖锁、迁移测试、页面测试和 Radio 时间表测试。

## 当前可靠性阶段（已于 2026-07-28 上线）
1. 5 分钟一次的 Web、数据库和 Radio 全链路健康检查。
2. 健康检查或备份失败时写入独立 journal 和最后失败状态。
3. 每日压缩 MySQL 备份、SHA-256 校验与 14 份精确保留。
4. 部署前完整代码快照、5 份保留和可识别部署版本。
5. 默认只预演的回滚命令，以及隔离 MySQL 容器恢复演练。

## 本阶段上线验收
1. 新 systemd unit 已通过服务器端校验并安装。
2. 真实健康检查已通过，5 分钟 timer 已启用。
3. 真实数据库备份已在临时隔离容器中恢复并查到核心表。
4. 回滚只运行 plan，未覆盖当前线上文件，也未回滚数据库。
5. 每日备份 timer 已启用并确认下次触发窗口。
6. 故障记录链路已通过无业务影响的瞬时失败自测。

## 仍然明确不覆盖
- 同盘备份不能应对整机或系统盘损坏，仍需要单独的异地备份方案。
- 当前故障记录只落本机 journal 和状态文件，不会主动发送邮件或消息。
- 自动化浏览器验证了 HLS 资源和元数据，但 Chromium 不提供原生 HLS
  播放能力，可听性仍需在支持 HLS 的真实用户浏览器中验收。

## 第二阶段（2026-07-28 已上线）
1. 统一为“夜鹿集 / YORUSHIKA ARCHIVE”视觉语言与站点命名。
2. 重做首页信息架构、作品封面比例与聆听路径。
3. 建立 8 张作品、63 首曲目的作品集和单曲详情页。
4. 恢复 20 首人工核对的 Bilibili MV / 影像入口。
5. 为桌面与手机端补齐筛选、曲序、前后曲目和无横向溢出布局。

## 第三阶段（2026-07-28 已上线）
1. 按 8 张发行作品的官方完整页面重新核对，不再以歌词页代替完整曲序。
2. 从 63 首补齐到 89 首，纳入器乐过场和《幻燈》的十个“夜”章节。
3. 保存精确发行日期、作品内曲序和来源复核日期，并提供可回滚迁移。
4. 人工核验影像入口从 20 首增至 24 首，不采用无法确认的翻奏或搬运链接。
5. 修复同作品共用封面时目录同步可能复用错误记录的问题。
6. 54 项自动化测试、桌面端和 390px 手机端浏览器验收均通过。

## 第四阶段（2026-07-28 发布候选）
1. 把 About 从通用开发者模板改为“关于夜鹿集 / 建站手记”。
2. 用数据库实时计算发行作品、完整曲序和已核对影像数量，避免固定文案过期。
3. 明确区分作品事实、个人笔记与私人 Radio 的访问边界。
4. 保留浏览器本地收藏，但把它降为策展说明之后的私人书架。
5. 54 项自动化测试、桌面端和 390px 手机端浏览器验收均通过。

## 第五阶段（2026-07-28 已上线）
1. 以《盗作》建立第一张完整作品档案页，集中展示官方背景、发行信息与来源。
2. 将官方事实与“本站聆听笔记”明确分开，个人章节划分不冒充官方结论。
3. 保留十四首官方曲序，并增加三段个人聆听路径、站内单曲页和五个已核对影像入口。
4. 首页作品脉络、作品集封面/标题、单曲面包屑均可进入或返回作品档案。
5. 部署拉取固定使用 HTTP/1.1，并增加三次有限重试，降低 GitHub 瞬时 HTTP/2
   传输错误造成的发布失败。
6. 57 项自动化测试、桌面明暗主题和 390px 手机端浏览器验收均通过。
7. 生产提交 `8119467` 已完成代码快照、数据库备份、目录同步、服务重启和真实
   页面验收；首次健康检查遇到 Radio 播放列表尚未生成，稍后重试后全链路通过。

## 第六阶段（2026-07-28 已上线）
1. 将目录从 8 部作品、89 条曲目记录扩展为 22 部官方发行作品、109 首独立曲目
   与 122 个曲序位置。
2. 拆分曲目、发行作品与作品曲序关系，同一首歌跨单曲、专辑收录时不再复制资料。
3. 补齐《二人称》和 13 部此前缺失的数字单曲，并保存官方封面、发行日期和来源。
4. 为 14 部暂无策展笔记的作品提供来源型概览页；只展示已核对事实，不虚构背景。
5. 单曲页支持作品上下文、同曲多作品收录与作品内前后曲目，旧重复链接会重定向到
   统一曲目地址。
6. 新迁移只增加作品与曲序表，保留旧曲目字段和数据，支持独立回滚。

## 第七阶段（2026-07-29 发布候选）
1. 逐项复核官方艺人目录中的 22 部音乐发行、109 首独立曲目与 122 个曲序位置。
2. 明确目录只覆盖 Yorushika 艺人标签下的音乐发行，不混入 Live 影像制品、
   书简型小说或 suis / n-buna 个人作品。
3. 对 24 个 Bilibili 入口只记录“页面可达且标题与曲目相符”，不再使用可能暗示
   官方授权的模糊表述。
4. 记录官方目录和第三方影像的最后人工核对日期，并以测试锁定当前 22 部发行清单。
5. 80 项自动化测试通过；桌面和 390px 手机端关键页面无控制台报错或横向溢出。

## 下一版
1. 为其余 14 部发行作品逐步补充有来源的策展笔记，不把自动生成内容当作品事实。
2. 优先补充官方 MV 或官方音乐平台入口；第三方链接继续人工核对，不用搜索结果自动填充。
3. 新发行作品出现时按相同模型增量收录，并保留核对日期。
4. 再决定是否增加服务端收藏、后台管理或独立 API。

## 非目标（当前阶段不做）
- 评论系统恢复。
- 用户上传图片恢复。
- 公开 Radio、音频下载和完整歌词转载。
- 未经来源核验自动生成作品事实、歌词或影像链接。
