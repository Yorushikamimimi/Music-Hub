# 迭代路线图（Roadmap）

## P0（上线前必须）
1. 数据库密码轮换并更新 `.env`。
2. 全站乱码文案修复（模板为主）。
3. 执行一次手工回归：`/`、`/search`、`/about`。

## P1（上线后一周内）
1. 增加 `README` 中的页面截图与示例数据说明。
2. 为搜索与首页增加最小集成测试。
3. 为 `config.py` 增加配置加载单元测试。

## P2（可选增强）
1. 引入 `API Layer`（API 层）。
  - 中文解释：将页面数据接口化，便于后续小程序/移动端复用。
2. 对收藏功能增加服务端持久化（用户体系上线后）。
3. 增加后台管理能力（数据修正、推荐位配置）。

## 非目标（当前阶段不做）
- 评论系统恢复。
- 音频在线播放恢复。
- 用户上传图片恢复。
