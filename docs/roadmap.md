# 迭代路线图（Roadmap）

## 本轮已实现（待服务器激活）
1. 静态资源减重与缓存。
2. 真实作品目录、Song Stories 和官方来源。
3. Radio 私密边界、24 首白名单与非自动播放。
4. 移动导航和基础无障碍，不改整体视觉语言。
5. 可回滚数据库迁移与确定性目录同步。
6. 移除伪 HOT / 评分。
7. Web / Radio 非 root 目标配置。
8. 哈希依赖锁、迁移测试、页面测试和 Radio 时间表测试。

## 上线门槛
1. 先做数据库迁移前检查，再执行 additive migration。
2. 安装非 root 服务配置并验证权限、socket 与 HLS。
3. 收口 MySQL 的公网监听。
4. 完成桌面端、手机端和真实 Radio 播放回归。
5. 保留旧音频目录与旧 Git commit，直到回归通过。

## 下一版（需要先看设计稿）
1. 统一 Yorushika 专属视觉语言与站点命名。
2. 重做首页信息架构、作品封面比例和故事阅读体验。
3. 把 About 从通用开发者模板改为本站策展说明。
4. 设计专辑/时期/主题关系页，而不是继续堆歌曲卡片。
5. 再决定是否增加服务端收藏、后台管理或独立 API。

## 非目标（当前阶段不做）
- 评论系统恢复。
- 用户上传图片恢复。
- 公开 Radio、音频下载和完整歌词转载。
- 在没有设计评审的情况下直接大改 UI。
