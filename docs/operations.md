# 运行与合规手册（Operations）

## 1. 启动前检查
- `.env` 必填项完整：`SECRET_KEY/DB_HOST/DB_USER/DB_PASSWORD/DB_NAME`。
- 数据库可连接，且存在 `music_yorushika` 数据。
- `static` 目录存在前端静态资源。

## 2. 运行命令
```powershell
python app.py
```

## 3. 合规基线
- 评论/留言：已下线。
- 音频彩蛋播放：已下线。
- 用户上传头像：已关闭。

## 4. 敏感信息管理
- 禁止在源码中写死密码或密钥。
- `.env` 不应提交到远端仓库。
- 定期进行 `SECRET_KEY` 与数据库密码轮换。

## 5. 变更后回归清单
1. 首页 `/` 可正常渲染。
2. 搜索 `/search` 可按条件过滤。
3. 关于页 `/about` 无上传入口、无报错。
4. 控制台无致命错误，后端无启动异常。

## 6. 故障排查
- 配置错误：优先检查 `.env` 是否缺项或有空格。
- 连接失败：检查 MySQL 服务状态和连接参数。
- 页面异常：先看模板语法，再看后端 traceback。
